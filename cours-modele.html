Maîtriser pfSense : Guide de démarrage

Temps de lecture estimé : 10 min • Niveau : Débutant

pfSense est l'une des distributions de pare-feu et de routeur open-source les plus puissantes du marché. Ce guide vous accompagne dans l'installation et la configuration initiale de votre passerelle réseau.

1. Prérequis et installation

Avant de commencer, assurez-vous de disposer d'une machine virtuelle ou physique équipée d'au moins deux interfaces réseau distinctes : une pour le WAN (Internet) et une pour le LAN (Réseau local).

2. Configuration des interfaces initiales

Lors du premier démarrage, pfSense vous invite à assigner vos cartes réseau :

  • Interface WAN : Reçue généralement en DHCP par votre box ou routeur d'accès amont.
  • Interface LAN : Configurée par défaut sur l'adresse IP 192.168.1.1.

3. Accès à l'interface d'administration web

Connectez un poste sur le réseau LAN, ouvrez votre navigateur web et entrez l'adresse IP du LAN. Connectez-vous avec les identifiants par défaut (admin / pfsense) pour accéder au tableau de bord sécurisé.
